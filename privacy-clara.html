Política de Privacidade

Última atualização: 1 de julho de 2026

1. Dados Coletados

O Clara Mel Post Manager coleta apenas as informações estritamente necessárias para o funcionamento do serviço:

  • Tokens de acesso: credenciais OAuth fornecidas pelas plataformas (TikTok, Instagram, Facebook) para autenticação. Armazenados localmente no dispositivo do usuário.
  • Identificadores de conta: IDs de usuário das plataformas conectadas, utilizados exclusivamente para publicação de conteúdo.
  • Conteúdo publicado: fotos e vídeos selecionados pelo usuário para publicação. O Aplicativo não armazena cópias permanentes desse conteúdo.

2. Uso dos Dados

Os dados coletados são utilizados exclusivamente para:

  • Autenticar o usuário nas plataformas conectadas
  • Publicar conteúdo nas contas autorizadas pelo usuário
  • Enviar notificações de status de publicação ao dispositivo do usuário

3. Compartilhamento de Dados

Não compartilhamos, vendemos ou transferimos dados pessoais a terceiros. Os dados trafegam exclusivamente entre o dispositivo do usuário e as APIs oficiais das plataformas (TikTok, Meta/Instagram/Facebook).

4. Armazenamento e Segurança

Todos os tokens e credenciais são armazenados localmente no dispositivo do usuário em arquivo .env. Não mantemos servidores próprios com dados de usuários.

5. Retenção de Dados

Os dados são retidos enquanto o usuário mantiver o Aplicativo instalado e configurado. O usuário pode revogar o acesso a qualquer momento através das configurações de privacidade das respectivas plataformas.

6. Direitos do Usuário

O usuário tem o direito de:

  • Revogar o acesso do Aplicativo às suas contas a qualquer momento
  • Solicitar a exclusão de quaisquer dados
  • Obter informações sobre os dados armazenados
